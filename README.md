## <img src="https://img.icons8.com/fluency/28/stars.png" width="22"/> &nbsp; Features

VitalSync brings together **six powerful health modules** in a single, beautifully designed dark-theme Android app:

<br/>

### <img src="https://img.icons8.com/fluency/22/home.png" width="18"/> &nbsp; Home Dashboard
- **Daily progress ring** — step count vs. 10,000-step goal with percentage completion
- **Quick stats** — distance (km), calories burned, and hydration tracking
- **Sleep summary** — last night's sleep with one-tap logging shortcut
- **Daily progress cards** — all key health metrics visible at a glance
- **SOS button** — persistent emergency button always visible at the top

### <img src="https://img.icons8.com/fluency/22/walking.png" width="18"/> &nbsp; Activity Tracker
- **Step counter** with animated circular progress visualization
- Tracks **distance (km)**, **calories burned (kcal)**, and **goal completion %**
- **Walk Tracker** — live GPS route rendered on map as you walk
- Manual step adjustment (+ / −) for treadmill or manual logging

### <img src="https://img.icons8.com/fluency/22/salad.png" width="18"/> &nbsp; Nutrition
- **Hydration tracker** — 8-glass daily goal with tap-to-toggle glass icons (+250ml each)
- **Calorie counter** — daily intake progress vs. 2,000 kcal daily target
- **Macro breakdown** — real-time Protein, Carbs, and Fat in grams
- **Meal Log** — add and track individual meals throughout the day

### <img src="https://img.icons8.com/fluency/22/dumbbell.png" width="18"/> &nbsp; Gym Tracker
- **Live workout session** with built-in elapsed timer
- **Quick-add exercises** — Bench Press, Squat, Deadlift, Pull-ups with one tap
- Log exercises with custom sets, reps, and weights
- **Rest Timer** — preset intervals: 30s / 60s / 90s / 120s
- Save and review completed workout sessions

### <img src="https://img.icons8.com/fluency/22/heart-health.png" width="18"/> &nbsp; Health
- **Sleep Tracker** — log sleep by time range (e.g. 23:00 → 07:00), with quality ratings
  - 7-day sleep history bar chart with recommended zone overlay (7–9h)
  - Stats: avg sleep duration, avg quality score (out of 5), and total sessions
- **BMI Calculator** — real-time BMI with color-coded scale (Underweight / Normal / Overweight / Obese)
- Weight and height input with persistent storage
- Emergency contact management

### <img src="https://img.icons8.com/fluency/22/sos.png" width="18"/> &nbsp; SOS & Fall Detection
- **Automatic fall detection** using device accelerometer sensor
- Full-screen red emergency alert with a **10-second countdown timer**
- Automatically calls emergency contacts and shares **live GPS location**
- **"I'M OKAY — Cancel SOS"** button to abort false alarms instantly
- Manual SOS trigger available at all times from the home screen

## <img src="https://img.icons8.com/fluency/28/rocket.png" width="22"/> &nbsp; Getting Started

### Prerequisites

| Tool | Version |
|---|---|
| <img src="https://img.icons8.com/fluency/20/android-studio--v2.png" width="16"/> Android Studio | Hedgehog or newer |
| <img src="https://img.icons8.com/fluency/20/java-coffee-cup-logo.png" width="16"/> JDK | 17+ |
| <img src="https://img.icons8.com/fluency/20/android.png" width="16"/> Android Device / Emulator | API 29+ |
| <img src="https://img.icons8.com/fluency/20/google-maps.png" width="16"/> Google Maps API Key | For walk tracker |

### Clone & Run

```bash
# Clone the repository
git clone https://github.com/sohiaking/VitalSync.git

# Open in Android Studio
# File → Open → Select the VitalSync folder
```

Then in Android Studio:
1. Wait for **Gradle sync** to complete
2. Add your **Google Maps API key** in `local.properties`:
   ```
   MAPS_API_KEY=your_api_key_here
   ```
3. Click **Run** or press `Shift + F10`
4. Select your device or emulator

### Build Release APK

```
Build → Generate Signed Bundle / APK → APK → Follow wizard
```
